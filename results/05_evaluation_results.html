1. Introduction

This document contains the evaluation metrics and visual results for the 3D SegResNet model trained on the BraTS 2023 dataset. The metrics were generated by evaluating the model on the unseen test split.

The key metrics computed per region are: - Dice Score: Overlap-based similarity. - Hausdorff95 (HD95): 95th-percentile surface distance (in mm). - Intersection over Union (IoU): Jaccard index. - Sensitivity: True positive rate. - Specificity: True negative rate.

The three regions evaluated are Whole Tumor (WT), Tumor Core (TC), and Enhancing Tumor (ET).

4. Statistical Distributions (Box and Violin Plots)

Box plots and violin plots are highly effective for visualising the distribution of metrics across the patient cohort, revealing outliers and the overall consistency of the model.

4.1 Dice Score Distribution

Code 
if 'df' in locals():
    plt.figure(figsize=(10, 6))
    custom_palette = ["#bfdbf7","#2A9D8F", "#E76F51"]
    ax = sns.violinplot(data=df, x="Region", y="Dice", inner="quartile", hue="Region", palette=custom_palette, legend=False)
    sns.stripplot(data=df, x="Region", y="Dice", color="black", alpha=0.3, jitter=0.2, size=3)
    plt.title("Dice Score Distribution across Test Patients")
    plt.ylabel("Dice Score")
    plt.ylim(-0.05, 1.05)
    plt.tight_layout()
    plt.savefig(results_dir / "figures" / "violin_dice.png", dpi=300)
    plt.show()
